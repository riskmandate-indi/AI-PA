## Real screenshots the user should add

Please replace each file with a real screenshot. Keep the same file name. PNG, JPG or HEIC all work.
Remove or blur anything private first. These files are committed to the repo.

- `flyer`: a photo of a paper flyer with a date and place.
- `poster`: a photo of an event poster taken at an angle.
- `chat`: a WhatsApp or iMessage screenshot that proposes a date. Ideally one where weekday and date disagree.
- `ticket`: a train, flight or event ticket screenshot.
- `diagram`: a whiteboard photo or a hand-drawn plan.
- `no-text-photo`: any photo with no writing in it.

Useful extras for M2 (new file names are fine): a handwritten note, a bill with a due date, a screenshot in a second language.
